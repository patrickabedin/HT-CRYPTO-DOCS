## What it is

`scripts/whatif_book.py` lane `EXPANDABLES`. Live calendars bank `EXPAND_STOP` / `EXPAND_BANK` and sit. This book keeps those tickets on per-ticket exits (TP / SL / STALL / MAX_HOLD / TICKET_TRAIL) and still admits TRIGGERED names after the live book sits.

SHADOW only. Never demo-attaches. Never places orders.

## Clock and size

Same USD 50 at 20x marks. Dashboard second calendar on `/?g=EXPANDABLES`.

## Radio

None.

## Host

State file **name** only: `expand_whatif.json`. Armed watcher adopts a live lock-flatten ticket via `whatif_adopt`.

## State / settle

What-if rows ingest as `book=whatif_nolock`. `WHATIF_OPEN` is a still-running mark.

## Gates

Max 3 open, one coin. No day sit. No $150 lock.
