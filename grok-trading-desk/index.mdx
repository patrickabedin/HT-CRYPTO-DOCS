Grok Trading Desk is the experimental LLM layer: Scout, Qualifier, Risk, Researcher, Telegram. It is **not** SKYNET-SOL.

Code: [`patrickabedin/grok-trading-desk`](https://github.com/patrickabedin/grok-trading-desk). Dashboard: [grok-trading-desk.vercel.app](https://grok-trading-desk.vercel.app).

<Warning>
  SHADOW / advisory. Never place, cancel, or withdraw **live** exchange orders. Bitget demo paper is opt-in only. Grade A stays **75**. Champion is not auto-promoted.
</Warning>

## Boundary

| System | Role |
| --- | --- |
| SKYNET-SOL | Deterministic engines and dashboard. No LLM in live signal, ranking, or risk. |
| Grok Trading Desk | LLM-assisted cards and research. Isolated `grok_desk` ClickHouse. SKYNET data is SELECT-only. |
| HT Crypto Docs | This site. All new desk documentation lands here. |

Do not put Grok-specific code in SKYNET-SOL. Do not copy or modify SKYNET engines from the desk repo.

## Where to look (names only)

| Place | What |
| --- | --- |
| GitHub `main` | Source of truth. No open PRs. |
| `/opt/grok-trading-desk` | Host checkout. Fast-forward every ~60s. |
| `/opt/grok-desk` | Copied market-data + watcher runtime. |
| `/opt/skynet-scalp` | Scalp / Cherry scout (other repo). |
| `/var/lib/grok-desk` | Desk locks, portfolio, `host_ff.json`. |
| `/var/lib/skynet-market` | Hunter / scalp / demo / settle state. |
| `/run/skynet-market` | `md.sock`, `latest.json`, `bars_5m.json`. |

Secrets live in host env files outside git. Do not paste values here.

Confirm the box caught `main` with `host_ff.json` (`fast_forwarded` or `up_to_date`).

## Hard operating rules

- Live Bitget API key is read-only
- Demo trading uses a Demo key and `paptrading: 1` only
- Only Chief of Staff publishes Telegram
- Shared Telegram budget: do not bypass `telegram_429_backoff`
- Land production code on `main`. No open PRs
- **New docs go in this Mintlify repo**, in the same turn as the change

Historical in-repo notes remain under `grok-trading-desk/docs/` as a snapshot.
