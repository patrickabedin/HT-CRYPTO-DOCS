## What it is

Closed candles are shared infrastructure. Only `grok-market-data` writes Valkey bar keys `sk:production:market:bars:v1:{SYMBOL}:1m|5m`.

`grok-market-files.timer` (60s) refreshes `/run/skynet-market/bars_5m.json` via `scripts/bars_snapshot.py`.

## Clock and size

On every **completed** 1m: append in-memory deque (maxlen ≥ 300), write Valkey, derive 5m from five completed 1m bars (floor timestamp), publish `bar_1m` / `bar_5m`.

Forming bars fill `open_bar` only. They are not persisted as closed.

## Radio

None.

## Host

`grok-market-data` + `grok-market-files.timer`. Watcher hydrates closed 1m before ticks so Grade A cold-start RVOL uses last closed vs prior closed.

## State / settle

Do not write `sk:production:streams:v1:*` from this path. Soak trade shards are not a candle source.
