## What it is

Canonical source: [`patrickabedin/grok-trading-desk`](https://github.com/patrickabedin/grok-trading-desk) `main`. **No open PRs.**

The droplet fast-forwards `/opt/grok-trading-desk` from `origin/main` about every 60 seconds (`grok-desk-ff-main.timer` → `deploy/ff_main.sh`). Confirm with `/var/lib/grok-desk/host_ff.json` (`fast_forwarded` or `up_to_date`).

Vercel deploys the dashboard from `main`.

## Clock and size

`ff_main` every ~60s. Fast-forward only. Do not reset a dirty checkout.

Oneshot timers load scripts on the next tick. Always-on units do **not**. After `desk_snapshot` / mark math changes, restart `grok-desk-realtime` so the publisher drops the old module. Do not restart `grok-market-data` for that.

## Radio

Deploy does not Telegram. Do not send test messages to verify a ship.

## Host

| Path | What |
| --- | --- |
| `/opt/grok-trading-desk` | Git checkout. Scripts load on the next timer tick. |
| `/opt/grok-desk` | Synced market-data + watcher (`deploy/sync_host.sh`). `RELEASE` is the copied commit. |
| `/opt/skynet-scalp` | Scalp / Cherry repo |
| `/var/lib/grok-desk` | Desk state |
| `/var/lib/skynet-market` | Hunter / scalp / demo / settle |
| `/run/skynet-market` | Live tape |
| `/etc/skynet-sol/grok-desk-*.env` | ClickHouse / Telegram env **files** (no values here) |
| `/etc/grok-desk/*.env` | Demo / watcher / dashboard env **files** |

`deploy/sync_host.sh` copies `market_data.py`, `watcher.py`, and `skynet_md/` to `/opt/grok-desk`.

Start market-data **first**, then the watcher consumer.

## Gates

- Do not run production from a home-directory loose copy
- Do not enable live trading, restart market-data, or press FLATTEN to test
- Treat worker deploy as confirmed only after `host_ff.json` or a live endpoint unique to that SHA
