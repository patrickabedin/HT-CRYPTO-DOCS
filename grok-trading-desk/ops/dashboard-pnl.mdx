## What it is

Production: [grok-trading-desk.vercel.app](https://grok-trading-desk.vercel.app).

Homepage is the UTC PnL calendar (`web/app/page.tsx`, `web/app/pnl-view.tsx`). Host job `scripts/desk_pnl_early.py` / `scripts/desk_pnl.py` merges settle books and POSTs `/api/ingest`.

Groups: `GRADE_B`, `GRADE_A`, `HUNTER_UNIQUE`, `HUNTER_TAPE`, `CHERRY`, `SCALP`, `DEMO`.

## Clock and size

`grok-desk-pnl.timer` every 60s. Calendar day is UTC close. The UTC clock ticks in the browser and rolls the date at midnight without a network request.

## Radio

None.

## Host

Ingest URL + shared secret live in the host dashboard env file and Vercel project settings. Env **names** only: `DESK_INGEST_SECRET`, `BLOB_READ_WRITE_TOKEN`, `REDIS_URL`.

## State / settle

Vercel Blob is the durable bootstrap store for the full PnL book. Fast marks travel on the realtime socket.

## Gates

Accounting integrity:

- `R` is stop-risk, not a dollar
- Grade A/B USD only when frozen entry and stop exist
- Hunter / Cherry / Scalp dollars are simulated signal-book PnL unless `exchange_stamped`
- Bitget Demo rows stay labeled separately
- `ALL` and `HUNTER` totals are not combined (overlap / different units)
- Impossible clocks, missing PnL, unknown funding, duplicate episodes are excluded

## How Patrick uses it

Filter with `?g=` and `?e=` (for example Grade B, or SCALP + USELESS_CLIP_GO). Do not treat simulated books as account equity.

On `/?g=GRADE_B` the **UTC day tape** has its own column per dollar level ($$30 / $$50 / $$80 / $$100 / $$150 / $$200 / $$300 / $$350 / $$400): how many times fill-true open-book uPnL crossed up through that dollar that UTC day. Clocks sit in a separate hits table (Athens). After a profit lock the book is flat, so the counts freeze. The tape day is UTC (resets 03:00 Athens in September). A stale-demo note on the LIVE line is a warning only — last-known seats still count and **new paper stays open**. Only `new entries blocked: demo file missing` closes admission. Watcher ticks write ClickHouse `grade_b_book_samples` / `grade_b_book_hits` so `scripts/grade_b_book_hits.py --day` can replay later. Samples start only after that writer ships; 15 Sep 2026 morning cannot reconstruct $$30/\$80.
