## What it is

`scripts/telegram_radio.py`. Desk / detect / settle / paper stay live. Only listed lanes may hit Bot API.

Lanes: `GRADE_B`, `GRADE_A`, `HUNTER`, `SCALP`, `USELESS`.

Default: `TELEGRAM_ALLOW=GRADE_B,GRADE_A`. Grade A sends only after TRIGGERED + a frozen plan.

## Clock and size

Not a timer. Evaluated on each would-be send.

## Radio

| Lane | Default | Publishers |
| --- | --- | --- |
| `GRADE_B` | on | chief `grade_b` + card edits |
| `GRADE_A` | on (trigger + frozen plan only) | Grade A fire |
| `HUNTER` | muted | ripe TAPE + brain UNIQUE |
| `SCALP` | muted | scalp / cherry (`run_scalp_telegram.sh`) |
| `USELESS` | muted | USELESS ENTER / clock |

Also need the per-lane knob: `SCALP_TELEGRAM=1`, `USELESS_TELEGRAM=1`, `HUNTER_UNIQUE_TELEGRAM=1`. Radio is the hard gate.

`TELEGRAM_ALLOW=GRADE_B` mutes Grade A. `ALL` restores every publisher. `NONE` mutes everything.

Host units installed before 2026-09-13 may still set `TELEGRAM_ALLOW=GRADE_B`. Drain / armed-watcher wrappers remap that leftover mute so Grade A can send. They do not unmute Hunter / SCALP / USELESS.

## Host

Env on the shared Telegram unit files. Do not document values.

## State / settle

None beyond the allow string.

## Gates

Scalp runner still refreshes `market_context.json` while muted.

## How Patrick uses it

Keep Hunter / SCALP / USELESS muted unless you ask. UNIQUE Hunter Telegram can be on in code defaults; host radio still mutes the `HUNTER` lane unless allowlisted.

## Decisions that still bind

Do not add a publisher that bypasses radio + 429 guard.
