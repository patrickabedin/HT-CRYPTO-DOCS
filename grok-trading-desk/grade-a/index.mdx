Grade A is the high band of the Scout / Champion path. Threshold **75**. A+ is **85+**. Raw Scout V1.4 component caps sum to 74; a bounded confluence bridge at the Champion layer can turn 74 into 75. Do not lower the threshold to hit a quota.

<Warning>
  SHADOW / advisory. Grade A stays off Bitget demo. Radio lane `GRADE_A` is on by default for **trigger-confirmed** cards only (TRIGGERED + frozen plan).
</Warning>

## What it is

Watcher events → drain cycle → Scout score → Champion rank → ARM gate. Qualifier / Risk / Chief only run on the live path after a real ARM / trigger. Most prints stay Grade F/B. That is OK.

## Clock and size

Drain every 60s. Scoring is local code, not an LLM. Size is not invented when equity is 0 — stop distance, invalidation, and R:R only.
