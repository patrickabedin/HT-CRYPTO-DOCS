## What it is

`scripts/grade_b_fills.py` is fill truth for the Grade B book. `scripts/grade_b_levels.py` stamps plan levels. `scripts/grade_b_upl_alert.py` alerts on open unrealized PnL.

Paper (ClickHouse / counterfactual) and Bitget demo USDT are different calendars. Open uPnL is not realized PnL.

<Warning>
  Public Bitget last and Bitget **demo** mark can diverge about 1% (SOL did). Matching paper to demo on the public tape is not honesty. See [13 Sep 2026 notes](/grok-trading-desk/grade-b/2026-09-13-upl-honesty).
</Warning>

## Clock and size

Levels come from the frozen TRIGGERED plan. Size is `$50` margin @ 20x (`$1000` notional). Paper closes deduct estimated trading fees. They do not model funding or execution slippage. Demo fills can differ.

Every paper open keeps **one fill**: Bitget fill if attached, else WS last with the 35 bps chase. Desk, tape, and lock mark that fill.

`R` is stop-risk. Grade A/B USD on the dashboard appears only when the rollup has frozen entry and stop and stamps that risk on the book's notional. Do not invent `1R = $50`.

## Mark source (13 Sep 2026)

`desk_snapshot.exchange_mark()` / `exchange_upl()`:

- **Attached** paper (same symbol+side on Bitget demo) uses Bitget `mark` / `unrealizedPL`.
- **Demo** rows use the same Bitget mark / uPnL.
- **Unattached** paper uses public WS last from `latest.json`.
- Signed zeros stay zeros.

Lock tape in `grade_b_portfolio.py` follows the same rule for attached paper. Do not remake both books from public last.

File mark can lag Bitget UI by one demo-trader tick (~15s). Compare REST `markPrice` + `unrealizedPL` when checking honesty.

After shipping snapshot math, restart `grok-desk-realtime`. It is long-running and keeps the old module in memory. Do not restart `grok-market-data`.

## Radio

HIGH alerts use `telegram_html` kind `grade_b_upl` (Hunter-style HTML: banner, pin, `HIGH +$n · opens`, advisory). Source `grade_b_upl_high`. Shared flood guard. Do not add a side channel. Do not test-send.

Rules: first touch ≥ `$30` on that book; later sends need a `+$1` new high vs the last **successful** send. UTC day resets paper and demo separately. State `/var/lib/grok-desk/grade_b_upl_alert.json` stores only the last alerted high per book — not a step list.

## Host

Called from armed watcher, demo trader, and PnL rollup. No dedicated public timer name beyond those workers.

## State / settle

- `/var/lib/grok-desk/grade_b_open_plans.json` — paper cache (`fill_entry`, `fill_source`)
- `/var/lib/grok-desk/grade_b_upl_alert.json` — HIGH watermarks
- `/var/lib/skynet-market/demo_trader.json` — demo fill + Bitget mark rows

Open-plan cache keeps unresolved positions (no silent 7-day drop). Plan versions stay in the cache for settlement attribution.

## Gates

Impossible clocks, missing PnL, unknown required funding, or duplicate setup episodes are excluded from the desk calendar and counted in metadata.

A first Bitget demo fill without card SL+TP is not covered. Empty `holdSide` does not count. Re-read, attach card levels, flatten **that** demo side if still unprotected.

## How Patrick uses it

`/?g=GRADE_B` shows paper vs Bitget demo. `/?g=DEMO` is demo-only. If desk paper and demo match each other but Bitget UI disagrees, check mark source — not SSR, not a dead WS.
