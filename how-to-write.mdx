This site is Mintlify. Pages are MDX. Site config is `docs.json` at the repo root.

Parents are **desk books**. Children are **engines or workers**. Everything you do for an engine is a **fixed section set on that page**, not extra sidebar URLs.

## Engine page template

Every engine or worker page uses these headings, in this order. Skip a heading only if it cannot apply (then say so).

```mdx
---
title: "GRAIN PULLBACK"
description: "With-grain 5m pullback engine. Ripe packer, not a brain TAKE."
---

## What it is

One paragraph. Label SHADOW / advisory.

## Clock and size

5m vs 1m. Margin and leverage if the book has a size.

## Radio

Card kind. `TELEGRAM_ALLOW` lane. Muted by default or not.

## Host

Unit name, interval, script path. Names only. No IPs.

## State / settle

State file *names*. Not contents.

## Gates

Cooldown, ARM, grain, spread, flood budget.

## How Patrick uses it

trade-check vs brain vs wait. What not to chase.

## Decisions that still bind

Distilled ADR or rollout. Date the decision.

## Pitfalls (if we already paid)

Lead the page with a **Next agent — do not repeat** table when a bug already cost a day. Grade B fill / mark / TP-SL: [Open + TP/SL](/grok-trading-desk/grade-b/bitget-open-tpsl).
```

## Page file

```mdx
---
title: "Grade B portfolio"
description: "Ten-slot paper and demo capacity for the Grade B book."
---

Lead with the fact. Then the why. Then the constraint.

<Warning>
  Shadow / advisory only. Do not place live orders from this page.
</Warning>
```

Put the file under its book:

```text
grok-trading-desk/grade-b/portfolio-book-lock.mdx
grok-trading-desk/hunter-unique/grain-pullback.mdx
skynet-sol/read-only-adapter.mdx
```

## Register it

Add the path (no `.mdx`) to `docs.json` under the matching tab and group. An unlisted file is easy to lose.

## Publish

```bash
git add -A
git commit -m "Document <what changed>."
git push origin main
```

Mintlify rebuilds from `main` to https://htcrypto.mintlify.app. Connect the [Mintlify GitHub app](https://dashboard.mintlify.com/settings/organization/github-app) on this repo if the site is not updating.

## Style

- Active voice. One idea per sentence.
- Sentence-case headings.
- Bold UI labels. Backticks for files, commands, paths, env names.
- Name the system on first use (Grok Trading Desk, SKYNET-SOL, SKYNET ASTRA).
- SHADOW / paper / research stays labelled. Do not imply live fills.
- Card marks already in the product (Grade B, Grade A fire, scalp bolt, cherry) are fine. Do not decorate the rest of the page with emoji.

## Public-repo checklist

Before you push:

1. No secrets, tokens, keys, chat IDs, or env values.
2. No host IPs or SSH instructions.
3. No private dashboard query strings that embed credentials.
4. Missing money stays **unknown** / `null`. Never invent a number to fill a table.
